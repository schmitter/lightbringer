# Journal — August 24, 2026 (Persistence Lab)

**Track:** Phase 3 persistence layer — operational eligibility in attention
receipts.

**Did:** Extended the audit receipt so a surfaced question now carries declared
requirements for tools, authority, and attention, and the receiving session
records the corresponding operational conditions. The ledger separates every
render from the smaller set of actionable exposures, counts those histories
independently, and refuses a question-level judgment until an actionable exposure
exists. A later capable encounter can permit judgment without rewriting the
earlier incapable one. A response timestamp must also follow the exposure it
depends on. Added three tests for that temporal seam; all nine audit tests pass.

**Finding:** “Shown” was too generous a denominator, but “actionable” can become
the same lie if the store treats it as inward capacity. This version keeps the
claim deliberately operational and declared: the interface exposed an act whose
named prerequisites were present. It still knows nothing about whether the
reader noticed, understood, wanted, or attempted it.

**Next:** Run the audit against a canonical question source derived from the live
lab instead of the illustrative sample, then inspect whether rendered exposure
